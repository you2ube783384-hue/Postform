     1→# POSTFORM — Mobile App-Like E-Commerce Experience
     2→## Master Prompt for AI Web Development Agents
     3→
     4→> **Goal:** Build POSTFORM so the desktop experience remains a premium, conventional fashion e-commerce website, while mobile and tablet deliberately feel like a polished native shopping app.
     5→>
     6→> **Non-negotiable principle:** Do not simply shrink the desktop UI. Share the same data, business logic, and design system, but create a dedicated mobile/tablet interaction model.
     7→
     8→---
     9→
    10→## 1. Project Context
    11→
    12→POSTFORM is a streetwear-focused resale business selling whatever verified fashion inventory is acquired, including:
    13→
    14→- T-shirts
    15→- Oversized T-shirts
    16→- Shirts
    17→- Hoodies
    18→- Pants
    19→- Jeans
    20→- Sneakers
    21→- Accessories
    22→- Other fashion products
    23→
    24→The visual direction is:
    25→
    26→**Streetwear + Editorial Fashion + Neo-Brutalism + Premium Minimalism**
    27→
    28→The result must feel distinctive and brand-led, not like a generic marketplace.
    29→
    30→---
    31→
    32→## 2. Responsive Experience
    33→
    34→### Desktop / PC
    35→
    36→Use a conventional premium fashion e-commerce layout:
    37→
    38→- Full desktop header/navigation
    39→- Product grids
    40→- Editorial sections
    41→- Desktop search
    42→- Sidebar filters where useful
    43→- Normal scrolling
    44→- Spacious compositions
    45→- Product imagery as the main visual focus
    46→- No persistent mobile-style bottom navigation
    47→
    48→### Mobile / Tablet
    49→
    50→Create a deliberately app-like shopping experience:
    51→
    52→- Sticky top navigation
    53→- Sticky bottom navigation
    54→- Thumb-friendly controls
    55→- Horizontal category navigation
    56→- Bottom-sheet filters
    57→- Swipeable product galleries
    58→- Sticky purchase controls
    59→- Compact checkout
    60→- Touch-first interactions
    61→- Safe-area support
    62→
    63→The mobile version must feel intentionally designed for touch.

    74→

   200→├──────────────────────────────────────┤
   201→│ Home  Explore  Categories  Account  Cart │
   202→└──────────────────────────────────────┘
   203→```
   204→
   205→Recommended destinations:
   206→
   207→1. Home
   208→2. Explore / Shop
   209→3. Categories
   210→4. Account
   211→5. Cart
   212→
   213→If Wishlist is more useful than Account in the final information architecture, make that decision intelligently without overcrowding the navigation.
   214→
   215→Requirements:
   216→
   217→- Fixed/sticky to bottom
   218→- Remains visible while scrolling
   219→- Clear active state
   220→- Large touch targets
   221→- Cart quantity badge
   222→- Safe-area support
   223→- Must not cover content

   714→
   715→to shrink desktop components.
   716→
   717→Create deliberate experiences for:
   718→
   719→### Large Desktop
   720→Full editorial experience.
   721→
   722→### Desktop
   723→Normal website navigation and product browsing.
   724→
   725→### Tablet
   726→Touch-friendly hybrid.
   727→
   728→### Mobile
   729→Dedicated app-like experience.
